# 元数据嵌入

设置入口：**设置 → 下载 → 元数据选项**。下载设置中的“为下载文件添加元数据”控制总开关，子选项只影响此后完成的下载，不修改已经保存的文件。

元数据是嵌入文件中的标题、艺术家、专辑、封面、歌词等信息，播放器可用它们显示和整理媒体。**歌词只嵌入选择“仅音频”后生成的音频文件；“音视频”和“仅视频”文件都不嵌入歌词。**下表中的歌词来源均以开启“嵌入音频歌词”为前提。

## 信息来源与含义

| 内容 | 标题 / 艺术家 | 专辑 / 编号 | 歌词来源 |
| --- | --- | --- | --- |
| 单 P 视频 | 稿件标题；可用 UP 主补充艺术家 | 只有真实的 UP 主合集才填专辑；不凭列表位置编造曲序 | 用户开启字幕转歌词后，取当前 aid/cid 的一种字幕 |
| 多 P 视频 | 当前分 P 标题；可用 UP 主补充艺术家 | 稿件标题作为所属作品；使用官方 page / pageCount | 当前分 P 的字幕 |
| 番剧、影视 | 单集标题及 long_title；不将上传账号或演员名单当歌手 | 季/作品名；只有明确数字集号才填曲序，SP、PV 不猜编号 | 当前单集的字幕 |
| 课程 | 课时标题；可用课程 UP 主补充艺术家 | 课程名；官方课时编号 | 当前课时的字幕 |
| 音频区 au | 歌曲标题；优先使用 author，缺失时才考虑 UP 主 | 接口未提供真实专辑，不拿歌名或歌单名填充 | song/info 的 lyric 原始 LRC；列表没提供地址时查询 song/lyric |
| 收藏夹、稍后再看、空间、歌单中的条目 | 补取条目本身的信息 | 这些列表本身不充当专辑或作品，也不提供曲序、作者、发布时间 | 按条目的真实类型处理 |
| 图文、封面图片、弹幕等附加文件 | 不应用音视频标签 | — | — |

- 视频封面取该稿件的封面，音频区取该歌曲的封面，不拿列表封面或分 P 首帧代替。
- UP 主、简介、普通 TAG、B 站发布时间和原始内容链接在备注中保留原义。普通 TAG 不是音乐流派，上传时间不是唱片发行或录制时间。
- 已标记为转载的视频不将 UP 主填入艺术家。音频区的 author 与 uname 分开处理，不从标题、简介、LRC 的署名猜测作词、作曲、流派或专辑艺术家。
- 多 P 作品优先按稿件归组，避免将每个稿件内部的 P1/P2 错当整个合集的轨道序号。合集没有可靠的全局音轨编号时留空。
- 番剧、课程只有当前完整列表的数字编号连续且从 1 开始时才填写总轨数；不拿已加载一页的长度当总数。
- 音频 au 关联的 BV 可能是不同剪辑，绝不把关联视频字幕写入 au 的歌词。
- 原始链接指向当前内容；视频分 P 带 `?p=`，课程和番剧定位到具体 ep。重试优先按 cid 找回原下载单元，曲序不再承担资源身份。

## 选项与默认值

| 选项 | 默认 | 行为 |
| --- | --- | --- |
| 嵌入封面 | 开 | 下载并校验图片，保持比例，限制解码尺寸后嵌入兼容的 JPEG |
| 嵌入音频歌词 | 开 | 仅对“仅音频”文件写入歌曲原始歌词或字幕转写；关闭后两者都不嵌入，字幕偏好仍保留 |
| 字幕转歌词 | 不使用 | 位于歌词开关所在的同一组内，可选“不使用”“仅人工”“允许 AI”；不影响音频区歌曲的原始歌词 |
| 用 UP 主补充艺术家 | 开 | 优先使用音频区歌曲作者；视频音轨等未提供作者的内容，用 UP 主填入艺术家供播放器显示。已标记的转载视频和番剧只在备注保留 UP 主；关闭此项也不影响已知的歌曲作者 |
| 将合集作为专辑 | 开 | 使用真实 UGC 合集；不改变多 P 作品、课程、剧集自身的归组 |

### 歌词来源和语言

音频区歌曲使用歌曲自身的原始歌词，不受“字幕转歌词”或解析页字幕语言的影响。视频、番剧、课程提取的音轨使用对应内容的字幕，需开启“字幕转歌词”。这里的 AI 字幕指 B 站已有的 AI 字幕，本功能不生成或翻译歌词。AI 与人工转写会在文件备注中注明来源。

字幕转歌词时，**每个音频文件只选用一种字幕语言**，不会把多种语言的字幕拼在一起。批量下载时，各文件可以选到不同语言。原始 LRC 按原文保留，不拆分其中可能已有的双语文本。

| 解析页的选择 | 音频文件内的歌词语言 |
| --- | --- |
| 单个条目，勾选“字幕”，并指定一种语言 | 只使用该语言；该语言不可用或其 AI 字幕未被允许时，不写入歌词，不改用其他语言 |
| 单个条目，未勾选“字幕” | 自动选择；之前选过的字幕语言不生效 |
| 单个条目，勾选“字幕”但语言选“全部” | 字幕文件可导出全部语言，内嵌歌词仍自动选择一种语言 |
| 批量下载 | 逐个音频文件自动选择；不会继承之前单选时的语言。勾选“字幕”仍会导出各条目的全部可用字幕文件 |

自动选择先按字幕来源，再按语言排序：

1. “仅人工”只考虑人工字幕；“允许 AI”优先人工字幕，没有人工字幕时才使用 AI 字幕。
2. 在同类字幕中优先简体中文，其次繁体中文，再其次其他语言；同优先级使用接口返回的第一种。
3. 没有符合偏好的字幕时，不写入歌词。例如，存在英语人工字幕和简中 AI 字幕时，“允许 AI”会自动选择英语人工字幕。

指定语言时只在该语言中选择，其他语言的人工字幕不会覆盖用户选中的 AI 字幕。“仅人工”则会排除这个 AI 选择，歌词留空。

“歌词语言如何选择”在歌词设置组内提供简明说明；上方的字幕偏好和解析页提示补充人工 / AI 限制。解析页选择“仅音频”时，会就地显示当前歌词来源、语言策略或关闭状态；提示与实际下载共用语言选择逻辑。

原始 LRC 保留时间戳、多时间戳及 offset；字幕按开始时间转换，保留停顿的清屏时间，过滤外部响应中的无效时间。不同播放器对内嵌 LRC 的滚动显示支持不同，仍可读取歌词文本；不宣称所有播放器都支持同步滚动。

## 容器与写入安全

| 输出 | 写入方式 | 封面 | 音频歌词 |
| --- | --- | --- | --- |
| MP3 | jaudiotagger 标准 ID3 | APIC，正面封面类型 3 | USLT |
| FLAC | jaudiotagger Vorbis Comment / PICTURE | PICTURE，记录真实尺寸 | LYRICS |
| M4A / MP4 / M4S | FFmpeg 流复制并写标准 MP4 标签 | covr / attached_pic，不增加普通视频轨 | 音频输出使用 ©lyr |
| MKV | FFmpeg 流复制 | JPEG 附件，按方向命名 cover.jpg / cover_land.jpg | 当前为视频混流输出，不写歌词 |
| FLV | FFmpeg 流复制，只加文字标签 | 不强塞不受支持的封面轨 | 当前为视频输出，不写歌词 |
| 原始 E-AC-3 等裸流 | 保留原件，显示格式不支持的提示 | — | — |

FFmpeg 保留原音视频编码、章节和动态视频轨，MP4 保留处理 Dolby Vision 所需的 `-strict unofficial`。FLAC 输出先检查真实文件头；DASH FLAC 仍在 MP4 容器中时先无损解封装，不能拿 `.flac` 后缀当格式判断。

MP3 使用标准 USLT 而不是 FFmpeg 6 将未知 `lyrics` 字段写出的 TXXX；歌词和备注帧使用 `und` 表示未声明语言，不猜英文或中文。FLAC 图片直接写 PICTURE 字段，绕开 jaudiotagger 对 AWT / ImageIO 的依赖。

所有修改先在同目录临时副本完成，完成后再替换。封面或歌词请求失败不会阻止其余字段；写入失败保留原文件，在下载完成信息中提示缺失项并记录诊断日志。取消时清理副本并传播取消，不吞掉取消信号。图片和原始 LRC 下载设有大小上限，编码错误及 HTML/JSON 错误响应不作为歌词保存。

## 验证

`EmbeddedMetadataBuilderTest` 覆盖各来源映射、列表隔离、分 P、转载及选项；`EmbeddedLyricsTest` 覆盖 AI 策略、语言、时间轴与错误响应；`EmbeddedAudioTagWriterTest` 对真实 MP3 / FLAC 做标签回读；`DownloadMetadataWriterTest` 在 Android 模拟运行环境检查资源开关、失败隔离、原件保护和设置持久化；`MetadataSettingsTest` 检查浅色/深色及 320dp 窄屏、1.6 倍字体下的字幕授权、父开关联动和语言说明，并逐帧验证展开收起的位置稳定性、验证下载子页面返回路径；`SubtitleSelectionTest` 与 `ParseLyricsSummaryTest` 检查单选、批量的语言策略及解析页提示。

可选的主机容器集成测试需要 FFmpeg / FFprobe。Windows 示例：

```powershell
$env:BILITOOLS_TEST_FFMPEG = 'C:/path/to/ffmpeg/bin'
./gradlew.bat :app:testDebugUnitTest --tests '*Embedded*Test'
```

`EmbeddedContainerRoundTripTest` 生成 MP4、分段 MP4、M4A、MKV、FLV，回读标签/封面，并比较所有原音视频包的 SHA-256，检查未重编码、未丢帧；同时覆盖 MKV 重复写入不追加重复封面。未设置该环境变量时只跳过这组主机集成测试。临时产物统一在 `.tmp/metadata/`，不连接设备。

测试资源 `app/src/test/resources/metadata/` 为 FFmpeg 生成的 0.25 秒 440 Hz 正弦波和 64×48 纯蓝图片，不包含真实用户音频。生成参数见集成测试中的 lavfi 用法。

## 依据

- 封面、歌词、艺术家、专辑与元数据总开关图标来自 [Google Fonts Material Symbols](https://fonts.google.com/icons)，使用 Rounded、400 字重、24px，分别为 `image`、`lyrics`、`artist`、`album`、`sell`。元数据选项复用设置页已有的 Rounded `tune` 调节图标。图标使用 Android VectorDrawable，来源采用 Apache-2.0 许可。
- 字幕选项使用 [Material 3 Expressive 连接式按钮组](https://m3.material.io/components/button-groups/overview)，与项目现有设置组件和语义配色保持一致。
- 本地 B 站文档：`../bilibili-API-collect/docs/audio/info.md`、`audio/music_list.md`、`video/info.md`、`video/player.md`。au13598 提供歌曲作者和独立原始 LRC。
- [ID3v2.4 原生帧定义](https://github.com/id3/ID3v2.4/blob/master/id3v2.4.0-frames.txt)：TALB 的作品含义、USLT 文本转写、APIC 封面。
- [FFmpeg 容器文档](https://ffmpeg.org/ffmpeg-formats.html)与 [FFmpeg 6 MP3 标签写入实现](https://github.com/FFmpeg/FFmpeg/blob/n6.0/libavformat/id3v2enc.c)。
- [Matroska 封面附件规范](https://www.matroska.org/technical/attachments.html)。
- [FLAC 格式文档及 RFC 9639](https://xiph.org/flac/format.html)。
- [Android BitmapFactory.Options](https://developer.android.com/reference/android/graphics/BitmapFactory.Options)：先读尺寸，再按采样率解码。
