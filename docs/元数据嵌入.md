# 元数据嵌入与内嵌字幕 / 歌词

写进媒体文件内部的内容分两类，入口不同、开关互不影响：

| 类别 | 内容 | 由谁决定 | 入口 |
| --- | --- | --- | --- |
| 元数据 | 标题、艺术家、专辑、备注、封面等标签，播放器用来显示和整理媒体 | 全局设置，对此后所有下载生效 | **设置 → 下载 → 为下载文件添加元数据 / 元数据选项** |
| 内嵌字幕与歌词 | 视频文件里的软字幕轨、音频文件里的歌词字段 | 每次下载在解析页单独勾选 | **解析页 → 下载与导出 → 内嵌字幕 / 内嵌歌词** |

字幕和歌词不是元数据：它们是文件里的一条条内容，用户对不同稿件的需求差别很大（要不要、哪几种语言），所以放在解析页逐次选择，而不是全局设置。元数据总开关关闭时，解析页勾选的字幕轨与歌词照常写入。子选项只影响此后完成的下载，不修改已经保存的文件。

## 元数据：信息来源与含义

| 内容 | 标题 / 艺术家 | 专辑 / 编号 |
| --- | --- | --- |
| 单 P 视频 | 稿件标题；可用 UP 主补充艺术家 | 只有真实的 UP 主合集才填专辑；不凭列表位置编造曲序 |
| 多 P 视频 | 当前分 P 标题；可用 UP 主补充艺术家 | 稿件标题作为所属作品；使用官方 page / pageCount |
| 番剧、影视 | 单集标题及 long_title；不将上传账号或演员名单当歌手 | 季/作品名；只有明确数字集号才填曲序，SP、PV 不猜编号 |
| 课程 | 课时标题；可用课程 UP 主补充艺术家 | 课程名；官方课时编号 |
| 音频区 au | 歌曲标题；优先使用 author，缺失时才考虑 UP 主 | 接口未提供真实专辑，不拿歌名或歌单名填充 |
| 收藏夹、稍后再看、空间、歌单中的条目 | 补取条目本身的信息 | 这些列表本身不充当专辑或作品，也不提供曲序、作者、发布时间 |
| 图文、封面图片、弹幕等附加文件 | 不应用音视频标签 | — |

- 视频封面取该稿件的封面，音频区取该歌曲的封面，不拿列表封面或分 P 首帧代替。
- UP 主、简介、普通 TAG、B 站发布时间和原始内容链接在备注中保留原义。普通 TAG 不是音乐流派，上传时间不是唱片发行或录制时间。
- 已标记为转载的视频不将 UP 主填入艺术家。音频区的 author 与 uname 分开处理，不从标题、简介、LRC 的署名猜测作词、作曲、流派或专辑艺术家。
- 多 P 作品优先按稿件归组，避免将每个稿件内部的 P1/P2 错当整个合集的轨道序号。合集没有可靠的全局音轨编号时留空。
- 番剧、课程只有当前完整列表的数字编号连续且从 1 开始时才填写总轨数；不拿已加载一页的长度当总数。
- 原始链接指向当前内容；视频分 P 带 `?p=`，课程和番剧定位到具体 ep。重试优先按 cid 找回原下载单元，曲序不再承担资源身份。

### 元数据选项与默认值

| 选项 | 默认 | 行为 |
| --- | --- | --- |
| 嵌入封面 | 开 | 下载并校验图片，保持比例，限制解码尺寸后嵌入兼容的 JPEG |
| 用 UP 主补充艺术家 | 开 | 优先使用音频区歌曲作者；视频音轨等未提供作者的内容，用 UP 主填入艺术家供播放器显示。已标记的转载视频和番剧只在备注保留 UP 主；关闭此项也不影响已知的歌曲作者 |
| 将合集作为专辑 | 开 | 使用真实 UGC 合集；不改变多 P 作品、课程、剧集自身的归组 |

元数据选项页底部说明字幕轨与歌词在解析页选择，不受此处开关影响。

## 内嵌字幕（视频）

解析页输出类型为「音视频」或「仅视频」时显示「内嵌字幕」分组：勾选「嵌入到视频文件」后，当前条目的可用字幕以多选 chip 列出，默认全选；取消勾选的语言不嵌入。字幕以**软字幕轨**写入容器，播放时可以切换或关闭，绝不渲染到画面里。

| 情形 | 行为 |
| --- | --- |
| 单个条目 | 嵌入勾选的语言，顺序保持 B 站列表顺序；取消最后一种语言等于关闭内嵌。切换条目后仍可用的勾选保留，一个都不剩时回到全部可用字幕 |
| 批量下载 | 语言随条目变化，不列 chip；每个条目嵌入自己的全部可用字幕，可用「包含 AI 字幕」决定是否连同 AI 生成的字幕一起嵌入 |
| FLV 音视频且未开启「将视频转换为 MP4 格式」 | FLV 不能存放字幕轨，勾选项禁用并提示改用 DASH / MP4 或开启转换；「仅视频」始终走 DASH 的 MP4 容器，不受影响 |
| 字幕列表仍在加载 / 获取失败 / 没有字幕 | 勾选项禁用，提示对应状态；批量下载不受当前条目的字幕状态限制 |

轨道写法：

- MP4 / M4S 使用 `mov_text`（tx3g）编码；MKV 直接保存 SubRip 文本。两者都通过 FFmpeg 以流复制完成，原音视频不重编码。
- 每条轨道写入 ISO 639-2 语言码：MP4 用 T 码（`zho`、`eng`），Matroska 用 B 码（`chi`、`eng`）。B 站的 `zh-Hans`、`ai-en` 等标签先去掉 `ai-` 前缀与地区 / 脚本子标签，再由 `Locale` 换成三字母码，见 `SubtitleLanguageCodes`；简繁差异三字母码表达不了，交给轨道标题保留。未知语言写 `und`。
- 轨道标题使用 B 站给出的语言名称（如「中文（简体）」「英语（自动生成）」）。MP4 没有独立的轨道标题字段，播放器展示的是 `hdlr` 处理器名称，因此同时写入 `handler_name`。
- 只有第一条轨道标为默认轨，其余显式清零，不同播放器的初始字幕才一致。
- 重试或再次保存时，输出里的字幕轨只来自本次选择，原有字幕轨不再映射，轨道不会翻倍；不嵌入字幕的普通元数据改写则保留文件里已有的字幕轨。
- 每种语言单独获取：个别语言失败只影响那一条轨道，其余照常嵌入，并在下载完成信息中提示「部分字幕获取失败」。没有任何字幕行的空文件按不可用处理。

## 内嵌歌词（音频）

输出类型为「仅音频」时显示「内嵌歌词」分组。音频文件只有一个歌词字段，因此**每个文件只放一种语言**：

| 来源 | 行为 |
| --- | --- |
| 音频区歌曲 | 写入歌曲自带的原始 LRC（song/info 的 lyric，缺失时查询 song/lyric）；与关联视频的字幕无关。原始 LRC 保留时间戳、多时间戳及 offset，不拆分其中可能已有的双语文本 |
| 视频 / 番剧 / 课程转出的音频，单个条目 | 用单选 chip 指定一种字幕转成 LRC；默认按人工优先、简体、繁体、其他的顺序预选一种。指定语言不可用时不写歌词，不悄悄换成另一种语言 |
| 批量下载 | 每个文件自动选择一种：人工字幕优先于 AI 字幕，再按简体、繁体、其他语言排序；「包含 AI 字幕」关闭时只考虑人工字幕 |
| 杜比全景声且未开启「将音频转换为 MP3 格式」 | E-AC-3 裸流不能写歌词，勾选项禁用并提示改选其他比特率或开启转换 |

字幕按开始时间转换为 LRC，保留停顿的清屏时间，过滤外部响应中的无效时间。AI 字幕指 B 站已有的 AI 字幕，本功能不生成或翻译歌词；转写来源（人工 / AI 字幕）记录在下载详情的「内嵌歌词」一栏。不同播放器对内嵌 LRC 的滚动显示支持不同，仍可读取歌词文本。

## 记住下载偏好

**设置 → 下载 → 记住下载偏好** 决定解析页「下载与导出」卡片里的哪些选项跨次解析保留。总开关之下按卡片分区逐组选择：输出类型、流媒体格式、分辨率与视频编码、音频比特率、内嵌字幕与歌词、字幕文件与 AI 总结、NFO 元数据、弹幕、图像、图文。

- 默认保留内嵌与各类附加导出项（它们没有别的默认来源），不保留输出类型、流格式与画质音质（各有自己的默认设置，每次解析回到默认值）。
- 被保留的分组在解析页更改后立即写入；画质与音质直接写回「默认下载质量」，不重复保存。
- 字幕语言、历史弹幕的日期与小时随条目变化，任何情况下都重新选择。
- 入口行以一句话汇总当前保留的分组；总开关关闭时，页面说明所有选项每次都回到默认值，分组开关变灰但保留原值。

## 容器与写入安全

| 输出 | 写入方式 | 封面 | 字幕轨 | 歌词 |
| --- | --- | --- | --- | --- |
| MP3 | jaudiotagger 标准 ID3 | APIC，正面封面类型 3 | — | USLT |
| FLAC | jaudiotagger Vorbis Comment / PICTURE | PICTURE，记录真实尺寸 | — | LYRICS |
| M4A / MP4 / M4S | FFmpeg 流复制并写标准 MP4 标签 | covr / attached_pic，不增加普通视频轨 | mov_text 轨，T 码语言 | 音频输出使用 ©lyr |
| MKV | FFmpeg 流复制 | JPEG 附件，按方向命名 cover.jpg / cover_land.jpg | SubRip 轨，B 码语言 | 视频混流输出，不写歌词 |
| FLV | FFmpeg 流复制，只加文字标签 | 不强塞不受支持的封面轨 | 不支持，提示未嵌入 | 视频输出，不写歌词 |
| 原始 E-AC-3 等裸流 | 保留原件，显示格式不支持的提示 | — | — | — |

FFmpeg 保留原音视频编码、章节和动态视频轨，MP4 保留处理 Dolby Vision 所需的 `-strict unofficial`。FLAC 输出先检查真实文件头；DASH FLAC 仍在 MP4 容器中时先无损解封装，不能拿 `.flac` 后缀当格式判断。

MP3 使用标准 USLT 而不是 FFmpeg 6 将未知 `lyrics` 字段写出的 TXXX；歌词和备注帧使用 `und` 表示未声明语言，不猜英文或中文。FLAC 图片直接写 PICTURE 字段，绕开 jaudiotagger 对 AWT / ImageIO 的依赖。

所有修改先在同目录临时副本完成，完成后再替换。封面、字幕或歌词请求失败不会阻止其余内容；写入失败保留原文件，在下载完成信息中逐项提示缺失（`EmbeddedContentIssue`），并记录诊断日志。取消时清理副本和字幕临时文件并传播取消，不吞掉取消信号。图片和原始 LRC 下载设有大小上限，编码错误及 HTML/JSON 错误响应不作为歌词保存。下载详情列出实际写入的字幕轨名称与歌词来源。

## 验证

`EmbeddedMetadataBuilderTest` 覆盖各来源映射、列表隔离、分 P、转载及选项；`EmbeddedLyricsTest` 覆盖字幕轨选择、歌词语言与 AI 策略、时间轴与错误响应；`MediaProcessingEngineTest` 检查字幕轨的输入顺序、映射、编码、语言码、默认轨标记与 FLV 拒绝；`EmbeddedAudioTagWriterTest` 对真实 MP3 / FLAC 做标签回读；`EmbeddedContentWriterTest` 在 Android 模拟运行环境检查元数据关闭时仍写歌词、无请求时不发网络、失败隔离、FLV 拒绝字幕、原件保护和设置持久化；`SubtitleSelectionTest` 覆盖解析页状态到下载请求的换算与语言回退；`ParseEmbeddingControlsTest` 在浅色 / 深色下截图并验证内嵌字幕多选、歌词单选、FLV 与杜比提示、批量下载的「包含 AI 字幕」；`MetadataSettingsTest` 检查元数据选项与父开关联动、下载子页面返回路径、「记住下载偏好」的总开关联动、摘要文案与持久化，含 320dp 窄屏、1.6 倍字体。

可选的主机容器集成测试需要 FFmpeg / FFprobe。Windows 示例：

```powershell
$env:BILITOOLS_TEST_FFMPEG = 'C:/path/to/ffmpeg/bin'
./gradlew.bat :app:testDebugUnitTest --tests '*Embedded*Test'
```

`EmbeddedContainerRoundTripTest` 生成 MP4、分段 MP4、M4A、MKV、FLV，回读标签/封面，并比较所有原音视频包的 SHA-256，检查未重编码、未丢帧；同时覆盖 MKV 重复写入不追加重复封面，以及 MP4 / MKV 软字幕轨的编码、语言码、轨道名、默认轨标记、UTF-8 文本回读、重试不叠加轨道与普通改写保留旧轨。未设置该环境变量时只跳过这组主机集成测试。临时产物统一在 `.tmp/metadata/`，不连接设备。

测试资源 `app/src/test/resources/metadata/` 为 FFmpeg 生成的 0.25 秒 440 Hz 正弦波和 64×48 纯蓝图片，不包含真实用户音频。生成参数见集成测试中的 lavfi 用法。

## 依据

- 图标来自 [Google Fonts Material Symbols](https://fonts.google.com/icons)，使用 Rounded、400 字重、24px：元数据相关为 `image`、`artist`、`album`、`sell`、`tune`；记住下载偏好及其分组为 `manage_history`、`movie`、`stream`、`video_settings`、`graphic_eq`、`subtitles`、`closed_caption`、`movie_info`、`forum`、`image`、`article`。图标使用 Android VectorDrawable，来源采用 Apache-2.0 许可。
- 解析页分组沿用 [Material 3 Expressive](https://m3.material.io/) 现有的分区标题、勾选行、筹码与提示行样式；语言 chip 以 `selectable` 暴露选中状态，读屏按复选框 / 单选项播报。
- 本地 B 站文档：`../bilibili-API-collect/docs/audio/info.md`、`audio/music_list.md`、`video/info.md`、`video/player.md`。au13598 提供歌曲作者和独立原始 LRC。
- [ISO 14496-12](https://www.iso.org/standard/83102.html) 媒体头中的语言为 ISO 639-2/T 三字母码；[Matroska 规范](https://www.matroska.org/technical/elements.html) 的 `Language` 元素使用 ISO 639-2/B 码。FFmpeg 的 mov 复用器把 `handler_name` 写入 `hdlr`，Matroska 复用器把 `title` 写入 `TrackName`。
- [ID3v2.4 原生帧定义](https://github.com/id3/ID3v2.4/blob/master/id3v2.4.0-frames.txt)：TALB 的作品含义、USLT 文本转写、APIC 封面。
- [FFmpeg 容器文档](https://ffmpeg.org/ffmpeg-formats.html)与 [FFmpeg 6 MP3 标签写入实现](https://github.com/FFmpeg/FFmpeg/blob/n6.0/libavformat/id3v2enc.c)。
- [Matroska 封面附件规范](https://www.matroska.org/technical/attachments.html)。
- [FLAC 格式文档及 RFC 9639](https://xiph.org/flac/format.html)。
- [Android BitmapFactory.Options](https://developer.android.com/reference/android/graphics/BitmapFactory.Options)：先读尺寸，再按采样率解码。
