# 彩蛋

BiliTools 里藏着一些不影响正常使用的小彩蛋。它们不弹对话框、不打断解析和下载，也不改动下载的文件。

首页小贴士可以在「设置 → 通用 → 首页小贴士」关闭；其余彩蛋没有开关。系统关闭动画时，待机小动作与彩纸不再播放。

## 文案与语言

彩蛋文案放在 `app/src/main/assets/easter_eggs/`，按语言各一份 JSON，不进 `strings.xml`：B 站梗基本没法翻译，强行凑齐 13 种语言反而失味。

- 简体中文、繁体中文提供完整词库，英文提供精简的通用版。
- 其他语言没有文案：首页小贴士与开关都不显示，台词类彩蛋只保留小电视的动作。
- 文案语言与界面语言的选择方式一致（`EggCopyLanguage.resolve`），系统语言都不支持时跟着界面回退到简体中文。

增删台词直接改 JSON。里程碑次数、日期、戳小电视的次数是代码里的固定键，改动这些键需要同步 `EasterEggRepository`、`EggCalendar` 与 `AboutMascotController`；`EasterEggLogicTest` 会检查三份词库的键是否齐全。开关、开发者选项等功能性文案仍放在 `strings.xml` 并覆盖全部语言。

## 代码位置

- 小电视：`ui/eggs/BiliTvMascot.kt` 用代码画出与应用图标一致的小电视，表情、天线、屏幕内容都能单独动；屏幕默认与图标一样镂空透出背景，影子按图标的柔光衰减绘制。
- 首页：`ui/eggs/HomeTips.kt`（选句逻辑 `HomeTipPicker`、状态 `HomeTipController`、横幅 `HomeTipBanner`）。
- 解析结果：`ui/eggs/ResultEggs.kt`。
- 关于页：`ui/settings/AboutMascot.kt`；开发者选项：`ui/settings/DeveloperOptions.kt`。
- 计数与里程碑：`data/EasterEggRepository.kt`，单独存放在 `easter_eggs` 偏好文件，与设置分开。
- 彩纸：`ui/eggs/ConfettiBurst.kt`，触发判断在 `ui/downloads/DownloadsCelebration.kt`。

## 效果图

`EggShowcaseScreenshotTest`、`MascotShowcaseScreenshotTest` 与 `DownloadsCelebrationShowcaseTest` 会把各个彩蛋的效果图和动画帧输出到 `.tmp/eggs/`，只用于人工查看，随时可以重新生成，因此不放进仓库。
