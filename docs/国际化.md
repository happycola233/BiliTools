# 应用语言

设置 → 通用 → 语言提供“跟随系统”和 13 种语言。首次启动不设置应用语言覆盖，直接使用系统语言列表；不支持的系统语言最终回退到简体中文。语言选项使用本名，方便用户在误选语言后恢复。

| 语言 | BCP 47 标签 | Android 资源目录 |
| --- | --- | --- |
| 简体中文 | zh-Hans | values-b+zh+Hans |
| 繁體中文 | zh-Hant | values-b+zh+Hant |
| English | en | values-en |
| 日本語 | ja | values-ja |
| Español | es | values-es |
| Português | pt | values-pt |
| اللغة العربية | ar | values-ar |
| Русский | ru | values-ru |
| Türkçe | tr | values-tr |
| ไทย | th | values-th |
| Bahasa Melayu | ms | values-ms |
| Tiếng Việt | vi | values-vi |
| Bahasa Indonesia | id | values-in |

简体中文在 `values/` 中提供完整默认资源，并在 `values-b+zh+Hans/` 中显式声明，以参与系统多语言列表的匹配。繁体中文使用脚本限定符，覆盖台湾、香港、澳门等使用繁体中文的地区。印尼语的 API 标签使用 `id`，资源目录使用 Android 的 `in` 限定符。

## 运行机制

- `AppLanguage` 和 `res/xml/locales_config.xml` 分别定义应用内选项与系统设置中的支持语言，测试会校验两者一致。
- `AppCompatDelegate.setApplicationLocales()` 是语言设置的唯一入口。空列表代表跟随系统。Android 13 及以上与系统的应用语言设置同步；旧版 Android 通过 AppCompat 的 `autoStoreLocales` 保存并迁移语言选择。
- Activity 沿用 `AppCompatActivity`。设置页声明接管 `locale|layoutDirection`，由 Compose 直接响应配置变化，保留窗口、滚动位置和正在进行的操作，避免切换语言时重建窗口闪屏；其它页面由框架重建并保留 ViewModel 中的解析结果。不要自行修改全局 Resources 配置，也不要在 SettingsRepository 再保存一套语言。
- 设置页保存更新检查的结果状态，使用 `stringResource` 生成当前语言的摘要；需要缓存格式化文案时，将 `LocalConfiguration.current` 纳入缓存键，不能只依赖不变的 Activity Context。
- 仓库和后台服务读取文案时使用 `StringProvider` 或 `localizedContext()`。Android 12 及以下的应用 Context 不会自动继承 AppCompat Activity 的语言。
- 展示层按当前配置解析状态和媒体类型，不使用已翻译字符串判断业务状态。文件名、服务器原文、用户内容与历史数据不因语言切换而改写。
- APK 包含全部语言；App Bundle 关闭语言拆分，使应用内切换不依赖下载额外语言包。
- Gradle `androidResources.localeFilters` 排除依赖库中的其它语言，防止系统多语言列表先命中仅依赖库支持的语言，导致应用文案错误回退。

## 新增和维护文案

默认文案按功能拆分在 `values/strings*.xml`，各语言保持相同文件组织。新增文案须同步到全部语言，保留编号占位符（例如 `%1$s`、`%2$d`）、命名模板变量（例如 `{pubtime:YYYY-MM-DD_HH-mm-ss}`）与 HTML 结构。换行使用 Android 的 `\n` 转义。品牌名、编码名称、格式标识和图标字形使用 `translatable="false"`，不要为其复制 13 份资源。

本轮非中文翻译以校对后的英文统一术语，繁体中文采用字词转换并检查产品用语。应用使用随包静态资源，不调用翻译服务。后续母语审校可直接修改对应 XML；保留 Bilibili 原始内容、分类名称及许可证原文，不将它们当作应用界面文案翻译。

数量短文案使用无单复数歧义的形式；时长单位和复数由平台 ICU `MeasureFormat` 处理，统计数量使用本地化紧凑数字格式。协议参数、文件扩展名与命名模板中的格式符保持语言无关。

## 布局和图标

阿拉伯语使用系统 RTL 配置。间距与对齐使用 start/end，返回箭头与导航箭头自动镜像，导航动画和底栏拖动方向跟随布局方向。语言页复用主题颜色，覆盖浅色、深色与大字体。

语言入口图标来自 [Google Fonts Material Symbols Rounded](https://fonts.google.com/icons?icon.style=Rounded&icon.query=language)，以本地 VectorDrawable 随包提供，不需要联网加载字体。原始路径见 `ic_language_rounded_24.xml` 注释。

## 验证

运行 `./gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:lintDebug`。

- `LocalizationResourcesTest` 检查所有语言的键集合、缺失与重复资源、占位符、命名变量和简体中文镜像。
- `AppLanguageTest` 覆盖 Android 10、12L、13、15 的语言声明、地区匹配、保存、跟随系统和后台 Context。
- `LanguageSettingsTest` 检查全部选项、深浅主题、RTL、大字体和导航父级。
- `SettingsLanguageChangeTest` 在 Android 12L、15 的实际设置 Activity 中检查语言切换、摘要刷新、RTL、窗口与导航/滚动位置保留。
- `LocaleResourceResolutionTest` 检查实际资源选择、中文地区匹配和系统多语言列表；`DownloadTextLocalizationTest`、`NotificationLanguageRefreshTest` 检查下载状态迁移和后台通知刷新。
- `LocalizedFormattingTest`、`DanmakuParserAssTest` 检查本地化数字、时间单位与字幕协议格式的隔离。
- Debug 构建启用 Android 伪语言，便于进一步检查文本扩展与 RTL；它们不列入正式语言选项。

可选媒体集成测试使用主机 FFmpeg，无需连接设备。将当前进程的 `BILITOOLS_TEST_FFMPEG` 设置为同时包含 `ffmpeg`、`ffprobe` 的目录后运行单元测试；官方杜比全景声样本测试另需 `BILITOOLS_TEST_ATMOS_SAMPLE` 指向样本文件，未配置时跳过。

参考：[Android 应用语言](https://developer.android.com/guide/topics/resources/app-languages)、[Android 本地化](https://developer.android.com/guide/topics/resources/localization)、[ContextCompat.getContextForLanguage](https://developer.android.com/reference/androidx/core/content/ContextCompat#getContextForLanguage(android.content.Context))、[Material Symbols](https://developers.google.com/fonts/docs/material_symbols)。
